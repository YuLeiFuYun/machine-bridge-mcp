# Changelog

## 3.0.0-beta.186 - 2026-09-12

- Recover a daemon-proven missing `read_job` after same-instance reconnect even when its remaining execution budget has fallen below the ordinary 10-second managed-read headroom: the redelivery degrades to one `wait_ms: 0` snapshot while preserving the original call ID, the original execution deadline, the fresh-call 10-second headroom gate, and the sub-1-second refusal boundary. Resume reconciliation is now connection-scoped: only the first acknowledgement whose missing IDs are a subset of the exact emitted `resume_calls` set can grant non-delivery authority; an exact duplicate acknowledgement is idempotent, while an out-of-scope or different subsequent acknowledgement is a protocol error. A pending call may still use only one successful transport redelivery, and a later reconnect that again proves non-delivery falls back to the existing retryable no-side-effect error instead of replaying the call again.
- Harden managed-job output redaction with one shared literal-pattern validator for both truncation-tail protection and final text replacement. Empty patterns, non-string entries, and malformed pattern collections are ignored consistently, and overlapping resource bytes, path variants, and literal patterns are processed longest-first across resources so a shorter protected prefix cannot expose the suffix of a longer secret. Resource materialization already produces non-empty string arrays; malformed-input handling remains defense in depth rather than evidence of a beta.185 production incident.
- Wire the existing Worker socket protocol-error counter to actual ready-channel rejection paths for both WebSocket and signed HTTPS fallback; only bounded error codes are counted, never daemon payload values.
- Record the beta.185 independent re-review boundaries: request-stream closure remains cancellation for request-scoped work, durable survival remains explicit Managed Job authority, the 2-second initial settlement window is unchanged absent host-side causal evidence, macOS path comparison keeps realpath-based alias handling without unsafe platform-wide lowercasing, accepted beta.179/beta.181 evidence is retained, and the fallback-proxy keep-alive hypothesis remains unproven.
- Advance package, Worker, and browser-extension prerelease identity to `3.0.0-beta.186`. This source candidate is not release-accepted by the version bump; publication and exact-candidate activation remain separately gated.

This review covers 37 distinct GitHub repositories. Each link below fixes the repository revision observed during this review. All 37 READMEs were retrieved; selected filesystem, retry, output, cache, proxy, browser and logging implementation documentation was also inspected. README-level feature descriptions are not a full source or security audit, and no benchmark ranking is inferred from them. Upstream marketing claims are not treated as measured evidence.

The adoption criterion is a reproducible local defect, a required dependency transition, or an existing invariant whose removal would change authority, settlement or resource bounds. No upstream code was copied and no new production dependency was added.

## Changes justified by local evidence

- A child exiting successfully with output containing a transient-network phrase was run three times. The retry classifier now checks successful settlement before reading output. The regression counts actual writes and covers stdout and stderr.
- Two 128-byte output buffers retained a 4 MiB producer allocation. Both append paths now trim before copying retained bytes. The new test bounds concatenation inputs, rejects producer-buffer aliasing, mutates the producer after append, and checks offsets/head/tail under 200 deterministic randomized partitions. Allocator pooling overhead is distinct from retained producer storage.
- Nested npm failures before script startup were suppressed by --silent, producing no causal output. Remove that redundant flag; the runner already suppresses successful child output. A real malformed-manifest regression requires the EJSONPARSE diagnosis.
- Workflow-policy fault tests searched for historical action commit text, so an otherwise valid action update failed before testing the policy. Select the currently pinned reference by action identity, while preserving immutable-SHA and unreviewed/dynamic-action denial checks.
- Update cf, Wrangler, ESLint and Node types after checking registry metadata and upstream release notes. Source/private manifests, locks, native-install allowlists, cf bundle hash and Worker type seed remain one candidate. These updates supersede the older dependency proposals rather than accepting an unverified manifest-only change.

## Simplification and retained boundaries

The unreachable head-fill branch after output overflow is removed. The cf offline test now exercises the pinned upstream exported network factory directly; it no longer appends an internal minifier symbol to a temporary third-party module. Current-candidate release notes replace superseded active-version text; prior details remain in Git history.

The three direct runtime dependencies remain necessary: ws supplies the relay transport; https-proxy-agent supplies the proxy agent accepted by ws and the HTTPS path; proxy-from-env supplies established proxy/exclusion semantics. Their call sites remain in relay/proxy code. Source cf/Wrangler dev dependencies support offline artifact and real Worker tests, while the private copy supplies consumer deployment without adding them to production dependencies. Removing either role would remove test/deployment coverage, not just duplication.

Legacy MCP initialization/session/replay markers remain bounded rejection paths, not compatibility implementations. Persisted security-state rejection, unknown-effect settlement, old-extension version negotiation and supported operating-system adapters are retained because deleting them would weaken explicit failure or interoperability contracts. A native feature available in Node 26 is not by itself proof that it preserves the project's proxy, process-tree or authority semantics.
